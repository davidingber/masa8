## הנחיות
- פורמט: **JPG**. משקל מומלץ לכל קובץ: עד ~300–400KB (נטענות בזמן אמת, לא מוטמעות).
- אותיות קטנות בשם הקובץ, בדיוק כמו בטבלה.
- טון: שקט, חמים, טבעי (ירוק-מרווה / שמנת / אור בוקר) — תואם לפלטת האפליקציה.
- העדפה: בלי אנשים (או רחוקים/אנונימיים), בלי טקסט על התמונה.
- אחרי שמוסיפים — לדחוף ל-main. התמונות יופיעו אוטומטית ברענון.
